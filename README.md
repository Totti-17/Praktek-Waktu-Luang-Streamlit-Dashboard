# Dashboard Penjualan

Dashboard interaktif sederhana menggunakan Python dan Streamlit. Masih dalam pengembangan(Tergantung authornya)

## Fitur
- Informasi total transaksi
- Total barang
- Total penjualan
- Filter kategori
- Grafik penjualan
- Tabel data

## Cara menjalankan

1. Install library:
   pip install -r requirements.txt

2. Jalankan aplikasi:
   streamlit run app.py
